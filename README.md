## ✨ Возможности

| Функция | Описание |
|---------|----------|
| 🎮 **Полная шахматная логика** | Все правила: рокировка, взятие на проходе, превращение пешек |
| 🤖 **Искусственный интеллект** | Глубина поиска: 4 полухода в режиме GUI, в режиме UCI адаптивная глубина от 2 до 6 |
| 📚 **Дебютная книга** | 50+ дебютных вариантов для реалистичной игры |
| 🎨 **Графический интерфейс** | Красивая доска, фигуры с загрузкой из интернета |
| 🔄 **Переворот доски** | Играйте за любой цвет с комфортом |
| 📋 **PGN экспорт** | Сохраняйте и копируйте партии в шахматный формат |
| 💾 **Позиционная оценка** | Учёт пешечной структуры, активности фигур и эндшпиля |
| ⚡ **Оптимизации** | Killer moves, History heuristic, Transposition table |

---

## 👋 Запуск

Движок можно запустить в 2 форматах:

1. Через встроенный Gui:  
Запустите файл gui.py (Должна быть установленна библиотека PyGame и сам Python)

2. UCI версия (Для Arena, Cute Chess):  
Скачайте и запустите через ваш интерфейс [файл](https://github.com/ExxDreamerCode/chess_engine/releases/tag/engineV2)
